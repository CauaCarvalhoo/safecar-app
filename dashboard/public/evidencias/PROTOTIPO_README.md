# Evidências fotográficas do protótipo — SafeCar

Nesta pasta também serão incluídas três fotos do grupo:

- `prototipo-app.webp`: captura do aplicativo com configuração de conexão ESP32;
- `prototipo-veiculo.webp`: montagem do ESP32, protoboard e módulo GPS no interior do veículo;
- `prototipo-monitor-gps.webp`: monitor serial com diagnóstico GPS. A versão preparada para publicação oculta dados sensíveis e não expõe a senha da rede.

Os arquivos são referenciados no bloco **Avaliação e validação** de `/sobre-nos`.

Para completar a inclusão dos arquivos binários, baixe o pacote de evidências fornecido na conversa e extraia sua pasta `dashboard/public/evidencias/` na raiz do repositório. Revise as fotos antes de publicá-las.
